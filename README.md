# TPO Programación III — Grupo Viedma
Luz Barrientos, German Rocha, Martina Cordoba

## Red Social Universitaria para la Colaboración

Trabajo Práctico Obligatorio de Programación III desarrollado en Java.

### Primera etapa

Se implementan las tres funcionalidades obligatorias:

1. Organización del muro de publicaciones
   - Merge Sort
   - Divide y Conquista

2. Cadena de difusión más rápida
   - Dijkstra
   - Greedy

3. Selección de iniciativas para financiar
   - Mochila 0/1
   - Programación Dinámica

### Segunda etapa seleccionada

- A3 — Selección de actividades compatibles
- B1 — Formación de equipos con restricciones
- B3 — Cadenas alternativas de difusión

### Ejecución

Ejecutar:

`src/redsocial/Main.java`

El programa funciona mediante un menú por consola.
